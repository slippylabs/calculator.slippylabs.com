# Calculator

A clean, keyboard-friendly calculator for everyday arithmetic. Runs entirely in your browser.

**Live:** <https://calculator.slippylabs.com/>

## What it does

- The four basic operations plus percent and backspace, on a button grid sized for touch.
- Fully keyboard-driven — digits, operators, `Enter` and `Backspace` all work.
- Shows the running expression above the result so you can see what you typed.

## Run it locally

A static site. No build step, no package manager, no dependencies:

```
git clone git@github.com:slippylabs/calculator.slippylabs.com.git
cd calculator.slippylabs.com
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
